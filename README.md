# MaquinaNorma

Projeto console em C# para simular operações de uma máquina de normas/aritmética.

## Requisitos

- .NET SDK 9.0

## Como executar

Abra o terminal na pasta do projeto e execute:

```bash
dotnet restore
dotnet run
```

## Menu principal

O programa apresenta um menu com opções para:

- Adição sem preservar conteúdo
- Adição preservando conteúdo
- Subtração
- Comparação menor que
- Comparação menor ou igual
- Resto da divisão

## Encerrar

Escolha a opção `*` no menu para sair.
